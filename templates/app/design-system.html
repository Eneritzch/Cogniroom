{# ============================================================ 5. MENSAJES (TOASTS) ============================================================ #}

Mensajes

Una sola superficie para feedback transitorio: errores de validación, confirmaciones, fallos de red. Arriba a la derecha. Nunca usamos alert(), confirm() ni los bubbles nativos del navegador.

Reglas
  • Una idea por toast. Si tienes que decir dos cosas, son dos toasts.
  • Mensaje en español natural, no códigos de log.
  • Duración: 4 s default · 1.5 s para confirmaciones cortas.
  • El form lleva novalidate; los errores nativos del navegador van por toast.
API 
import { toast } from '/static/app/js/toast.js';

toast('Sesión sincronizada');                              // info
toast('Hola, María', { kind: 'success', duration: 1500 }); // verde
toast('Credenciales inválidas.', { kind: 'error' });       // rojo
