Mascota del sistema CogniRoom.

Suelta aquí 3 imágenes PNG (fondo transparente recomendado):

  idle.png   -> neutral / mientras el estudiante responde
  happy.png  -> cuando responde bien
  sad.png    -> cuando responde mal

Aparece (esquina inferior derecha) en: dashboard del estudiante,
Diagnósticos, detalle de tema y la sesión de evaluación.

Cuando agregues las imágenes, borra el bloque marcado "PLACEHOLDER"
en static/css/app/components/mascot.css para quitar el recuadro guía.
Tamaño sugerido: ~240x240 px.
